# Notesflow for Homebrew

Install [Notesflow](https://github.com/AndreaUnali/notesflow) on macOS or Linux.

```sh
brew install AndreaUnali/notesflow/notesflow
notesflow
```

For editing and PDF preview, install Neovim and Poppler if you need them with `brew install neovim poppler`.

Update with `brew upgrade AndreaUnali/notesflow/notesflow`.

To publish a new version of the formula, download `notesflow-bottle-formula.rb` from the matching [GitHub release](https://github.com/AndreaUnali/notesflow/releases) and replace `Formula/notesflow.rb` here.
